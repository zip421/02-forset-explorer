## Описание проекта 
Двухмерная приключенчиская игра в пиксильном стиле, игрок может ходить по ранее созданому лесу, наполненому кострами, палаткой и ресурсами

## Стек проекта 
* **Игровой движок / Платформа:** Godot Engine 4.7
* **Язык программирования:** GDScript
* **Дополнительные инструменты:** Git 

## Что было использовано в проекте 
* **Узлы (Nodes):** CharacterBody2D, AnimatedSprite2D, Label, Node
* **Паттерны / Подходы:** Глобальный код (Autoload, singleton), сигналы, автомат анимаций(State based Animation)
* **Ресурсы:** Кастомные спрайты, UI-шрифты
